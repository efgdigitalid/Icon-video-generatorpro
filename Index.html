Cara Deploy ke GitHub Pages (file HTML) — klik untuk buka
  1. Klik tombol ⬇️ Unduh index.html di bawah. Browser akan menyimpan seluruh aplikasi ini (satu file) sebagai index.html. Tips Android: file masuk ke folder Download — pindahkan/rename bila perlu. PC: alternatif — buka menu browser → Save Page As → pilih Webpage, Single File / HTML Only → simpan dengan nama index.html.
  2. Buka github.com/new, buat repo baru (contoh: icon-video), pilih Public, centang Add a README.
  3. Di repo baru, klik Add file → Upload files, seret index.html ke sana, lalu Commit changes.
  4. Buka tab Settings → Pages. Di bagian Source pilih Deploy from a branch, Branch: main / folder /(root), klik Save.
  5. Tunggu ±1 menit. URL akan muncul di halaman itu: https://<username>.github.io/icon-video/.
  6. Buka URL tersebut di Android/PC — aplikasi jalan langsung dari browser. 🎉
Jika Android tidak mengizinkan unduh otomatis: tekan lama di kotak kode → Pilih Semua → Salin → buat file baru bernama index.html di editor teks, lalu upload ke GitHub.
